# 🌙 موقع أذكار الصباح والمساء | Morning & Evening Adhkar

موقع عربي جميل يعرض أذكار الصباح والمساء **الصحيحة الموثقة بمصادرها** من الكتاب والسنة.

## ✨ المميزات
- 🌅 أذكار الصباح (22 ذكراً) و 🌙 أذكار المساء (21 ذكراً)
- كل ذكر مع: النص الكامل + عدد التكرار + الفضل + المصدر ورقم الحديث + درجة الصحة
- عداد تفاعلي + شريط تقدم + حفظ تلقائي
- 📿 مسبحة إلكترونية
- 🔍 بحث + ⭐ مفضلة + 🌙 وضع ليلي
- 📅 تاريخ هجري وساعة حية

## 📚 المصادر
صحيح البخاري، صحيح مسلم، سنن أبي داود، سنن الترمذي، سنن النسائي، مسند أحمد — مع أحكام الشيخ الألباني رحمها الله، وكتاب حصن المسلم.

## 🚀 التشغيل
افتح `index.html` في المتصفح مباشرة — لا يحتاج سيرفر.

## 🌐 النشر عبر GitHub Pages
من إعدادات المستودع: Settings → Pages → Deploy from branch → `main` → `/ (root)`
